# 11. 보안 및 저작권 보호 체크리스트 (Security Checklist)

## 1. 웹툰 IP 저작권 및 콘텐츠 보호
- [x] **공식 라이선스 계약 기간 검증**: 만료일(`endDate`)이 경과한 웹툰 IP는 에디터 및 스토어에서 자동 비활성화 처리
- [x] **승인된 에셋 화이트리스트 관리**: 공식 등록된 캐릭터, 스티커, 프레임 에셋만 캔버스 로딩 허용
- [x] **워터마크 및 해상도 분리**: 스토어 미리보기에서는 경량 저화질 썸네일 제공, 인쇄 렌더링 시에만 정밀 벡터/고화질 렌더러 동작
- [x] **클라이언트 무단 도용 방지**: 저작권 침해 방지를 위한 인라인 SVG 보호 및 출처 명시

---

## 2. 결제 및 주문 무결성 보안
- [x] **클라이언트 결제 금액 위변조 차단**: 주문 접수 시 수량 × 단가 + 배송비를 서버 및 스토어 로직에서 재계산하여 금액 불일치 시 트랜잭션 중단
- [x] **결제 민감정보 비보관**: 카드번호, CVC, 비밀번호 등은 직접 저장하지 않으며 결제사 트랜잭션 ID(`transactionId`)만 보관
- [x] **테스트 모드 명확한 시각적 고지**: 가상 결제창 및 시뮬레이션 환경에 '테스트 모드' 뱃지 항시 표기

---

## 3. 키오스크 7자리 인쇄 코드 보안
- [x] **추측 불가 난수 생성**: 시퀀스 번호가 아닌 7자리 난수(`Math.random` 기반 균등 분포)로 발급하여 브루트포스(무차별 대입) 차단
- [x] **엄격한 유효기간(72시간) 적용**: 만료 일시 이후 요청 시 즉각 400 거절 처리
- [x] **일회성 출력(Single-use) 보장**: 1회 출력 완료(`isPrinted = true`) 즉시 상태 변경되어 중복 인쇄 원천 방지
- [x] **출력 로그 기록**: 키오스크 기기 ID(`kioskId`) 및 정확한 출력 타임스탬프 영구 감사 로그 기록

---

## 4. 관리자 권한 및 접근 제어
- [x] **RBAC(역할 기반 접근 제어)**: `ADMIN` 역할을 가진 사용자만 백오피스(`/admin`) 및 정산 API 접근 허용
- [x] **일반 사용자 경로 격리**: 일반 팬(`USER`) 계정 상태에서 관리자 대시보드 접근 시 안내 및 접근 차단
