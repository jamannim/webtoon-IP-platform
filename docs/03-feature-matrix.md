## 2. 외부 연동 한계 및 시뮬레이션 명시 사항
1. **결제 (PG)**: 실제 사업자 등록 및 PG사(토스페이먼츠, NHN KCP 등) 계약 전이므로 웹 표준 인터페이스를 따르는 '테스트 모드 가상 결제창'으로 구동
2. **키오스크 장비 출력**: 실제 무인 출력 키오스크(DNP 포토프린터 및 윈도우 단말기) 통신 API 확보 전이므로 웹 기반 '키오스크 터치스크린 시뮬레이터'로 완전하게 대체하여 테스트
3. **택배사 API**: CJ대한통운/우체국 등의 실제 API 연동 전이므로 가상 운송장 번호 생성 및 배송 파이프라인 시뮬레이션으로 제공
