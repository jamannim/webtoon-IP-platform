## 2. 완전 제외 항목 (Explicitly Excluded Scope)

*사용자 지침에 따라 서비스 정체성 집중을 위해 명시적으로 제외 확정된 항목입니다.*

1. **일반 문서 / A4 복사용지 인쇄 (PDF, HWP, 오피스 등)**:
   - **제외 사유**: 툰캔버스는 관공서/행정용 복합기 인쇄 서비스가 아닌 **K-웹툰 IP 디지털 굿즈 버티컬 플랫폼**이므로, 일반 A4 문서 출력은 일체 제공하지 않음.
   - **하드웨어 간소화**: 고비용 A4 레이저 복합기 모듈을 제외하고, 300 DPI 포토인화지 전용 프린터 및 스티커 라벨 엔진에 집중하여 키오스크 제작 단가 및 유지보수 비용을 획기적으로 절감.
2. **비인가/무단 웹툰 이미지 업로드**:
   - 공식 라이선스가 체결되지 않은 외부 임의 이미지 인쇄는 원천 차단하며, 검증된 공식 IP 에셋만 출력 허용.

## 3. 후속 개발 범위 (Post-MVP / Future Roadmap)

1. **실제 무인 키오스크 펌웨어/하드웨어 연동**:
   - DNP / 후지필름 염료승화형 포토프린터 윈도우 단말기 드라이버 및 직렬(Serial/USB) 통신 SDK 연동
   - 키오스크 현장 IC/MS 카드리더기 VAN사 연동
2. **실제 PG사 상용 계약 및 API 연동**:
   - 토스페이먼츠(Toss Payments) / 스마트로 / KG이니시스 실거래 결제창 및 Webhook 승인 검증
3. **전문 인쇄소 자동 주문 접수 API (Web-to-Print API)**:
   - 주문 완료 시 300DPI 인쇄용 PDF/CMYK 분판 파일 자동 생성 후 인쇄소 FTP/API 전송
4. **모바일 네이티브 앱 (iOS / Android)**:
   - React Native 또는 Flutter 기반 키오스크 위치 기반 푸시 알림 및 블루투스 원터치 인쇄
