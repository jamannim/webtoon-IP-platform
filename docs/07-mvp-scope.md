# 07. MVP 개발 범위 및 후속 로드맵 (Scope & Roadmap)

## 1. MVP 범위 (In-Scope for Current Release)

| 영역 | 세부 항목 | MVP 구현 형태 | 비고 |
| :--- | :--- | :--- | :--- |
| **IP 및 콘텐츠** | 4개 대표 장르 오리지널 웹툰 IP | 벡터/SVG 공식 에셋 및 캐릭터 일러스트 완비 | 저작권 침해 없는 순수 자체 제작 에셋 |
| **굿즈 스튜디오** | 캔버스 WYSIWYG 에디터 | 요소 선택, 이동, 스케일링, 회전, 레이어 z-index, 텍스트 편집, 안전선 가이드 | React + HTML5 Canvas |
| **인쇄 규격** | 포토카드, 엽서, 스티커, 아크릴 | 300 DPI 환산 해상도 및 재단/안전 여백 가이드 | 실시간 해상도/품질 진단기 포함 |
| **출력 모듈 A** | 7자리 키오스크 인쇄 코드 | 난수 발급, 72시간 만료 타이머, QR 시각화 | 무인 키오스크 연동 표준 규격 |
| **출력 모듈 B** | 오프라인 키오스크 시뮬레이터 | 가상 키패드 터치, 코드 검증, 출력 공정 애니메이션 | 하드웨어 없이 100% 기능 검증 가능 |
| **배송 모듈** | 택배 배송 주문 제작 | 배송지 입력, 운송장 번호 생성 및 상태 관리 | 포토카드 외 스티커/아크릴 지원 |
| **결제 모듈** | 국내 PG 결제창 | 가상 결제 모달 (토스페이, 카카오페이, 카드 시뮬레이션) | 트랜잭션 ID 발급 및 무결성 검증 |
| **마이페이지** | 디자인 보관함 및 주문 내역 | 프로젝트 임시저장/재편집, 주문 상태 조회, 취소/환불 | LocalStorage + State 영속화 |
| **관리자** | 백오피스 대시보드 | IP 라이선스 관리, 주문 상태 제어, 로열티 정산 테이블 | `/admin` 경로 제공 |

## 2. 후속 개발 범위 (Post-MVP / Future Roadmap)

1. **실제 무인 키오스크 펌웨어/하드웨어 연동**:
   - DNP / 후지필름 염료승화형 포토프린터 윈도우 단말기 드라이버 및 직렬(Serial/USB) 통신 SDK 연동
   - 키오스크 현장 IC/MS 카드리더기 VAN사 연동
2. **실제 PG사 상용 계약 및 API 연동**:
   - 토스페이먼츠(Toss Payments) / 스마트로 / KG이니시스 실거래 결제창 및 Webhook 승인 검증
3. **전문 인쇄소 자동 주문 접수 API (Web-to-Print API)**:
   - 주문 완료 시 300DPI 인쇄용 PDF/CMYK 분판 파일 자동 생성 후 인쇄소 FTP/API 전송
4. **모바일 네이티브 앱 (iOS / Android)**:
   - React Native 또는 Flutter 기반 키오스크 위치 기반 푸시 알림 및 블루투스 원터치 인쇄
