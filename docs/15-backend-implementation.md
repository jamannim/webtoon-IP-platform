# 15. 백엔드 및 관리자 백오피스 구현 보고서 (Backend Implementation)

## 1. 백엔드 엔드포인트 구현 내역

| 엔드포인트 | 메서드 | 담당 기능 | 입출력 검증 및 처리 |
| :--- | :--- | :--- | :--- |
| `/api/projects` | GET, POST | 디자인 프로젝트 CRUD | 사용자 ID별 필터링, 필수 필드(title, productId, ipId) 검증 |
| `/api/orders` | GET, POST | 주문 접수 및 조회 | 주문 금액 및 상품 항목 유효성 검증 |
| `/api/kiosk/verify` | POST | 7자리 인쇄 코드 검증 | 난수 포맷 정제, 72시간 만료 검증, 일회성(중복 인쇄 방지) 체크 |
| `/api/kiosk/print` | POST | 키오스크 출력 완료 처리 | 출력 완료 타임스탬프 기록 및 기기 ID 매핑 |
| `/api/admin/settlement` | GET | IP별 로열티 정산 집계 | 총 매출, 작가별 로열티액, 플랫폼 수수료 요약 집계 |

---

## 2. 관리자 백오피스 (`/admin`) 기능 및 접근 제어
1. **RBAC 권한 제어**:
   - `ADMIN` 권한을 가진 계정만 접근 가능하며, 일반 사용자의 경우 안내 모달 및 계정 전환 옵션 제공
2. **종합 통계 대시보드**:
   - 총 매출액, 키오스크 출력률, 활성 웹툰 IP 수, 작가 로열티 정산 예정액 실시간 카드 표시
3. **웹툰 IP 및 라이선스 관리**:
   - 공식 승인 작품 목록 조회, 원클릭 제작 활성화/일시정지 토글
4. **주문 및 배송 관리**:
   - 택배 주문에 대한 운송장 번호 등록 및 발송완료 처리
   - 키오스크 출력 주문의 7자리 인쇄 코드 및 출력 상태 모니터링
5. **로열티 정산 (Settlement)**:
   - IP별 판매량, 총 매출, 계약 요율(12%~18%), 정산 지급액 자동 계산 테이블 제공
