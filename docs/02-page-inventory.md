# 02. 페이지 인벤토리 (Page Inventory)

## 1. 기존 참고 서비스 페이지 목록
| No. | 페이지명 | 경로/URL | 주요 제공 기능 |
| :--- | :--- | :--- | :--- |
| 1 | 메인 홈 | `/` | 서비스 소개, 7자리 인쇄코드 입력 바, 주요 지점 안내, 공지 배너 |
| 2 | 프린팅박스 찾기 | `/find` | 지도 API 기반 전국 무인 키오스크 매장 검색 및 운영 현황 |
| 3 | 파일 업로드 | `/upload` | 문서/사진 파일 선택, 기본 여백 및 부수 설정, 인쇄코드 발급 |
| 4 | 이용안내/요금표 | `/guide` | 상품 규격(4x6, 6x8, A4) 및 이용 단가, 사용 가이드라인 |
| 5 | 크리에이터 굿즈 | 콘텐츠박스 연동 | 작가별 인쇄코드 공유 피드 및 굿즈 상세 정보 |
| 6 | 마이페이지 | `/mypage` | 회원 기본정보, 과거 출력 이력, 발급 코드 유효기간 조회 |

## 2. 신규 WEBTOON GOODS PLATFORM (TOON CANVAS) 페이지 인벤토리

| ID | 화면명 | 라우트 경로 | 반응형 | 주요 기능 및 구성 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **P-01** | 메인 랜딩 | `/` | 모바일/PC | 비주얼 히어로 배너, 실시간 인기 웹툰 캐러셀, 추천 굿즈 템플릿, 키오스크 빠른 코드 조회 바, 서비스 장점 |
| **P-02** | 웹툰 IP 스토어 | `/store` | 모바일/PC | 장르별 필터(SF, 로판, 학원, 힐링), 검색, 공식 라이선스 배지, 작품 카드 목록 |
| **P-03** | 작품 상세 | `/store/[ipId]` | 모바일/PC | 작품 시놉시스, 캐릭터 목록(성우/스펙/태그), 제작 가능 굿즈 규격 및 가격표, '제작 시작' CTA |
| **P-04** | 굿즈 커스텀 에디터 | `/editor` | 모바일/태블릿/PC | WYSIWYG 캔버스, 캐릭터/스티커/프레임 에셋 팔레트, 텍스트 타이포그래피, 인쇄가이드(Bleed/Trim/Safe), 300DPI 품질 검사, 임시저장/내보내기 |
| **P-05** | 주문 및 결제 | `/checkout` | 모바일/PC | 주문 상품 및 수량 확인, 후가공 옵션(용지/코팅), 수령방식 선택(키오스크 즉시 vs 택배), 가상 PG 결제 모달 |
| **P-06** | 주문 완료 & 인쇄코드 | `/order/complete/[orderId]` | 모바일/PC | 7자리 대형 인쇄 코드 발급, 72시간 실시간 카운트다운 타이머, 바코드/QR, '키오스크 시뮬레이터 바로가기' CTA |
| **P-07** | 키오스크 시뮬레이터 | `/kiosk` | 터치 최적화/태블릿/PC | 무인 키오스크 화면 UI, 7자리 가상 키패드 터치 입력, 코드 검증, 출력물 렌더링 애니메이션, 완료 영수증 |
| **P-08** | 마이페이지 | `/mypage` | 모바일/PC | 내 저장 프로젝트(재편집/삭제/주문), 주문/출력 내역 조회, 인쇄코드 재확인, 택배 배송추적, 취소/환불 모달 |
| **P-09** | 운영자 백오피스 | `/admin` | 데스크톱/태블릿 | 관리자 통계 대시보드, IP/라이선스 관리, 굿즈 규격 관리, 주문/출력 상태 갱신, IP별 로열티 정산 테이블 |
