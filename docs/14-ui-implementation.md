# 14. 프론트엔드 사용자 화면 구현 보고서 (UI Implementation)

## 1. 구현된 주요 화면 목록 및 완성도

| 화면 경로 | 화면명 | 구현 기술 | 주요 기능 및 인터랙션 |
| :--- | :--- | :--- | :--- |
| `/` | 메인 랜딩 | React 19 + Tailwind v4 | 비주얼 히어로, 인기 웹툰 캐러셀, 추천 굿즈 그리드, 빠른 키오스크 코드 조회 위젯 |
| `/store` | 웹툰 IP 스토어 | React 클라이언트 필터링 | 장르별 탭(SF/로판/학원/힐링), 실시간 검색, 정렬(인기/최신), 공식 인증 배지 |
| `/store/[ipId]` | 작품 상세 페이지 | 동적 라우팅 (Next.js 16) | 작품 시놉시스, 공식 캐릭터 목록(성격/스펙 태그), 제작 가능 굿즈 규격 및 가격표 |
| `/editor` | 굿즈 커스텀 에디터 | HTML5 Canvas + 2D 엔진 | 캐릭터/스티커/프레임 에셋 추가, 텍스트 타이포그래피, 인쇄가이드(Bleed/Safe), 300DPI 진단기, 임시저장/고화질 렌더링 |
| `/checkout` | 주문서 및 결제 | 가상 PG 시뮬레이터 | 수량/용지/코팅 옵션, 수령 방식(키오스크 즉시 vs 택배), 금액 자동 계산, 가상 결제창 |
| `/order/complete/:id` | 주문 완료 & 인쇄코드 | Canvas Confetti + 72h 타이머 | 7자리 대형 인쇄코드 발급, 복사 기능, 키오스크 시뮬레이터 바로가기 |
| `/mypage` | 마이페이지 | LocalStorage 영속화 | 내 디자인 보관함(재편집/삭제), 주문 및 출력 내역, 취소 및 환불 모달 |

## 2. 반응형 웹 및 인터랙션 검증
- **모바일 뷰포트 (360px ~ 480px)**:
  - 단일 컬럼 카드 그리드 및 모바일 햄버거 드로어 메뉴
  - 캔버스 에디터 줌/팬 및 터치 컨트롤 고려
- **태블릿 & 데스크톱 뷰포트 (768px ~ 1280px+)**:
  - 좌측 에셋 팔레트, 중앙 캔버스 워크스페이스, 우측 속성 인스펙터 3단 스튜디오 구조

---

## 3. 샘플 콘텐츠와 승인된 IP 콘텐츠의 격리
- 공식 라이선스 계약이 확인된 4개 오리지널 웹툰 IP(스텔라 나이트, 황실의 비밀 온실, 언더독 하이, 달묘의 다락방)는 전용 벡터 아트워크 및 메타데이터로 안전하게 분리 제공됨.
- 외부 사이트(프린팅박스)의 소스코드나 비인가 이미지는 일체 복제되지 않음.
