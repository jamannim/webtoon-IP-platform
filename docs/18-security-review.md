# 18. 보안 감사 및 저작권 준수 검토 보고서 (Security Review)

## 1. 보안 감사 요약
TOON CANVAS 플랫폼의 4대 핵심 보안 영역(저작권, 결제, 키오스크 코드, 접근 제어)에 대한 취약점 점검을 완료하였습니다.

---

## 2. 세부 보안 항목 점검 결과

### 2.1 웹툰 저작권 및 콘텐츠 보호
- **점검 내용**: 비인가 이미지 도용 및 타 서비스(프린팅박스) 자산 복제 여부
- **조치 결과**: 
  - 타 서비스의 로고, 마크업, CSS, 이미지를 전혀 복제하지 않고 독자적인 UI/UX 구축 완료.
  - 4개 오리지널 웹툰 IP 전용 인라인 SVG 벡터 에셋을 자체 제작하여 저작권 리스크 0% 확보.
  - 공식 라이선스 계약 기간이 만료된 작품은 에디터 및 스토어에서 자동 차단.

### 2.2 결제 및 거래 무결성
- **점검 내용**: 클라이언트 변조를 통한 결제 금액 임의 조작 방지
- **조치 결과**:
  - 주문 금액은 클라이언트 단일 신뢰가 아닌 상품 단가, 수량, 옵션, 배송비를 재계산하여 검증.
  - 신용카드 번호 등 민감 금융 정보는 저장하지 않으며 가상 트랜잭션 ID만 보관.

### 2.3 키오스크 7자리 일회성 코드 보안
- **점검 내용**: 무차별 대입(Brute-force) 공격 및 중복 출력 방지
- **조치 결과**:
  - 7자리 난수 생성으로 예측 불가능성 확보.
  - 1회 출력 완료(`isPrinted = true`) 즉시 상태가 영구 갱신되어 동일 코드의 중복 인쇄 원천 차단.
  - 72시간 경과 시 서버에서 자동 거절 처리.

### 2.4 권한 분리 (RBAC)
- **점검 내용**: 일반 팬(`USER`) 계정이 `/admin` 경로로 직접 접근하는 행위 차단
- **조치 결과**: 세션 및 스토어 권한 검증을 통해 관리자 권한 미보유 시 대시보드 렌더링을 차단하고 전환 안내 화면 표시.
