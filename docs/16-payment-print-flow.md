# 16. 주문·결제 및 무인 키오스크 출력 파이프라인 명세 (Payment & Print Flow)

## 1. 결제 및 출력 파이프라인 상태 전이 다이어그램

```mermaid
stateDiagram-v2
    [*] --> DRAFT : 캔버스 에디터에서 편집
    DRAFT --> ORDER_CREATED : 주문서 작성 (/checkout)
    ORDER_CREATED --> PAYMENT_PENDING : 가상 PG 결제창 호출
    
    state PaymentProcess {
        PAYMENT_PENDING --> PAID : 결제 승인 성공 (PG 수수료 3.3% 자동 분개)
        PAYMENT_PENDING --> PAYMENT_FAILED : 승인 거절/한도초과 (감사로그 기록)
    }
    
    PAID --> READY_FOR_PICKUP : 키오스크 출력 선택 (7자리 코드 발급)
    PAID --> PRODUCING : 택배 배송 선택 (인쇄소 제작)
    
    READY_FOR_PICKUP --> PRINTED : 키오스크 터치 입력 & 인쇄 완료 (단말기 기록)
    READY_FOR_PICKUP --> EXPIRED : 72시간 경과 만료 (자동 취소/환불)
    READY_FOR_PICKUP --> REFUNDED : 사용자 취소/환불 요청
    
    PRODUCING --> SHIPPED : 운송장 등록 및 택배사 발송
    SHIPPED --> DELIVERED : 고객 배송 수령 완료
    
    PRINTED --> [*]
    DELIVERED --> [*]
    REFUNDED --> [*]
```

## 2. 결제 PG 수수료(3.3%) 및 IP 로열티 정산 공식

| 항목 | 계산 공식 | 설명 |
| :--- | :--- | :--- |
| **총 결제액 (Gross Revenue)** | $\sum (\text{단가} \times \text{수량}) + \text{배송비} - \text{할인액}$ | 고객이 실제로 결제한 총 금액 |
| **PG 결제대행 수수료 (PG Fee)** | $\text{총 결제액} \times 3.3\%$ (원 단위 반올림) | 토스페이, 카카오페이, 네이버페이, 카드사 공통 수수료 |
| **차감 후 순매출액 (Net Revenue)** | $\text{총 결제액} - \text{PG 결제대행 수수료}$ | 라이선스 계약 정산의 기준 금액 |
| **IP 작가 로열티 지급액 (Royalty)** | $\text{순매출액} \times \text{계약 로열티율 (\%)} $ | 원작 웹툰 작가/CP사에 지급되는 정산금 |
| **플랫폼 순수익 (Platform Net Margin)** | $\text{순매출액} - \text{IP 작가 로열티 지급액}$ | 플랫폼 운영사 잔여 마진 |

## 3. 모듈별 검증 및 테스트 시나리오

### 3.1 시나리오 1: 7자리 인쇄 코드 발급 및 키오스크 출력
1. **발급 검증**: 주문 완료 시 7자리 난수(예: `748-2918`)가 고유하게 발급되며 유효기간 72시간 타이머가 시작됨.
2. **코드 조회 검증**: `/kiosk` 시뮬레이터에서 7자리 입력 시 서버에서 정확한 주문 상품, 옵션, 고화질 렌더링 파일 확인.
3. **출력 공정 시뮬레이션**: '인쇄 시작' 버튼 클릭 시 롤러/프린터 진행률(0% -> 100%) 시뮬레이션 후 하단 배출구로 배출.
4. **일회성(Single-use) 재사용 차단 검증**: 출력이 완료된 후 동일한 코드를 재입력하면 "이미 출력이 완료된 코드입니다" 에러 안내 표시.

### 3.2 시나리오 2: 택배 배송 및 관리자 운송장 등록
1. 택배 배송 선택 시 배송비(3,000원) 자동 가산 및 주소지 필수 입력 확인.
2. 결제 완료 후 마이페이지에서 '배송 준비 중' 상태 확인.
3. `/admin` 백오피스에서 운송장 번호 입력 시 '배송중' 및 운송장 번호 실시간 동기화 확인.

### 3.3 시나리오 3: 출력 전 취소 및 환불
1. 키오스크 출력 전 상태에서 마이페이지 '취소/환불' 버튼 클릭 시 즉각 환불 처리 및 발급 코드 무효화.

### 3.4 시나리오 4: 운영 감사로그(Audit Logs) 세부 이슈 추적
1. **하드웨어 장애 추적**: 키오스크 용지 걸림(`ERR_PRINTER_JAM_TRAY1`), 칼날 마모(`CRIT_CUTTER_BLADE_WEAR`), 잉크 부족 발생 시 즉시 심각도 배지 및 설치 지점 주소와 함께 감사로그 생성.
2. **현장 조치 연계**: 상세 모달에서 원시 페이로드 JSON, 에러 원인 및 '현장 대응 가이드' 확인 후 관리자가 '조치 완료(RESOLVED)'로 즉시 상태 변경 가능.
