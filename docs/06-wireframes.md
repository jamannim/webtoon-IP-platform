## 2. 굿즈 커스텀 에디터 (`/editor`)
```
+-------------------------------------------------------------------+
| [< 뒤로가기]  스텔라 나이트 - 포토카드 편집기   [임시저장]  [최종 주문하기]  |
+-------------------+-----------------------------------+-----------+
| [에셋 팔레트]      | [ 캔버스 작업 영역 (300 DPI) ]      | [속성 패널] |
| - 공식 캐릭터     | +-------------------------------+ | - 레이어   |
|   (레이, 에리카)  | | [Bleed 여백 2mm (빨간 점선)]  | |   - 텍스트 |
| - 공식 스티커     | |  +-------------------------+  | |   - 스티커 |
|   (스파클, 리본)  | |  | [Safe Zone 3mm (초록선)]|  | |   - 캐릭터 |
| - 프레임/말풍선   | |  |                         |  | | - 정렬     |
| - 텍스트 추가     | |  |       (선택된 캐릭터)    |  | | - 폰트/크기 |
| - 배경 색상       | |  +-------------------------+  | | - 회전/투명도|
|                   | +-------------------------------+ |           |
|                   | [줌: 100%] [가이드선 ON/OFF]       | [품질 진단]|
|                   | [실시간 품질: 300 DPI 최적 (초록)]  | 650x1004px|
+-------------------+-----------------------------------+-----------+
```
